## 操作

- Enter：从据点开始对战
- WASD：移动；右键拖动：旋转镜头；滚轮：缩放
- 左键：普攻；空格：闪避
- Q / E：技能；R：满能量大招
- Tab：锁定；Esc：暂停；F：据点喂食

当前为单人对 AI 的几何体原型，包含据点、即时对战、结算和本地存档。没有真实数码宝贝模型或联网。

32 项源码功能检查通过，Linux 打包版本完成运行检查；Windows 包已导出，尚未在 Windows 实机试玩。压缩包内包含操作说明与第三方许可。校验值见 SHA256SUMS.txt。
